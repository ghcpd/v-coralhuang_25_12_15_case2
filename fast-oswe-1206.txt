## 🔧 Implementation notes
### Goals and what I changed
- **Eliminated duplication**: shared validation, payload building, logging, and response handling in `BaseTool`.
- **Consistent behavior**: refactored tools now use the same payload shape (snake_case keys + stripped query), identical validation rules, and consistent error messages.
- **Compatibility**: public `run` signatures and return value shape unchanged; existing code (input_demo.py, original tools) remain intact.

### Files in detail
- refactored_tools.py  
  - Shared `BaseTool` with validation (`_validate`), payload builder (`_build_payload`), logging (`_log`) and response handler (`_send`).
  - New `ToolA`, `ToolB`, `ToolC` **extend `BaseTool`** and simply call the shared methods. This keeps the public interface identical.

- test_tools.py  
  - Tests assert both **original behaviors** (preserving the current, possibly inconsistent contracts) and the **refactored behavior** (consistent payload + validation).
  
- run_tests  
  - A tiny script to run pytest at the repo root: run_tests (or `python run_tests`) will run the tests and exit non-zero on failure.
